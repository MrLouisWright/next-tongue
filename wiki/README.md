# Wiki pages (fallback)

The GitHub wiki repository is not initialised until a first page is created via the web UI, so these pages are kept here. To publish: create any page at https://github.com/MrLouisWright/next-tongue/wiki, then `git clone https://github.com/MrLouisWright/next-tongue.wiki.git` and copy these files in (excluding this README).

Regenerate from `docs/` after doc changes.
